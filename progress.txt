OAUTH DCR PROXY + DEPLOY (2026-05-12 → 2026-05-13):
- claude.ai MCP connector couldn't reach /mcp — Clerk doesn't support
  RFC 7591 Dynamic Client Registration natively (no registration_endpoint
  in its oauth-authorization-server metadata)
- Built a proxy fronting Clerk in apps/glowlytics/backend/mcp/oauth-proxy.js:
  - POST /oauth/register — RFC 7591, returns our pre-registered Clerk
    client_id (XszcYauNAWSpoz98) for every caller; static, no per-caller
    state since we share one Clerk OAuth app
  - GET /oauth/authorize — 302 to Clerk with rewritten client_id +
    our /oauth/callback URL, opaque 24-byte state token (10-min TTL)
    maps to caller's state in-memory; PKCE params forwarded
  - GET /oauth/callback — looks up caller state, 302s back to original
    redirect_uri with Clerk's code + caller's original state
  - POST /oauth/token — Basic-auths to Clerk with client_id+secret,
    rewrites redirect_uri to our callback so Clerk accepts the swap
- well-known.js conditionally advertises our backend as auth_server
  when MCP_OAUTH_PROXY_ENABLED=true; falls back to Clerk otherwise
- auth.js: WWW-Authenticate header on /mcp 401 (RFC 9728) +
  cfg.allowedClientIds Set auto-includes MCP_OAUTH_PROXY_CLIENT_ID
- 21 oauth-proxy.test.js tests across 6 describe blocks; mocks global
  fetch for token-endpoint coverage; verifies Basic auth + redirect_uri
  rewrite + opaque-state round-trip + feature-flag-off 404s
- Railway env: MCP_OAUTH_PROXY_ENABLED=true,
  MCP_OAUTH_PROXY_CLIENT_ID=XszcYauNAWSpoz98,
